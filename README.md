# homebrew-tap

Homebrew tap for [Tired IT Humans](https://github.com/tiredithumans) tools.

One tap, one formula per project. A tap is just a repository with a `Formula/`
directory: Homebrew resolves `tiredithumans/tap/<name>` to `Formula/<name>.rb`
in here, so adding a project means adding one file — there is no reason for
each project to carry a tap of its own.

## Install

```sh
brew install tiredithumans/tap/<formula>
```

That taps and installs in one step. To tap once and then install by bare name:

```sh
brew tap tiredithumans/tap
brew install <formula>
```

Homebrew reads this tap over git, so a formula is only installable by someone
who can clone **this** repository. Access follows this repo's visibility, not
the linked project's.

## What's in here

| Formula | Project | What it is |
| --- | --- | --- |
| `crt-query` | [crt-query](https://github.com/tiredithumans/crt-query) | Query crt.sh certificate-transparency data straight from its public PostgreSQL database |

## Upgrade

```sh
brew update
brew upgrade <formula>   # or plain `brew upgrade` for everything
```

That is the reason a tap is worth maintaining: `brew upgrade` finds new
versions on its own, where a downloaded binary has to be replaced by hand.

## How this tap is maintained

Every file under `Formula/` is **generated** in its own project's repository and
lands here as a copy. The `version` and `sha256` values are read out of a
published release's checksums, so they cannot drift from the archives they name
— never edit them by hand. Regenerate at the source and replace the file.

| Formula | Regenerated by |
| --- | --- |
| `crt-query.rb` | `just homebrew-formula` in the [crt-query](https://github.com/tiredithumans/crt-query) repo, which rewrites it from a published release's `SHA256SUMS` |

## Adding a project

1. Generate the formula in that project's repo and keep it checked in there, so
   the generator and its output stay together.
2. Copy it here as `Formula/<name>.rb`.
3. Check it before anyone relies on it:

   ```sh
   brew tap tiredithumans/tap
   brew install --formula tiredithumans/tap/<name>
   brew test <name>
   brew audit --strict --online tiredithumans/tap/<name>
   ```

   `brew audit` only runs against a formula that is already inside a tap, which
   is why the source repo cannot gate on it.
4. Add a row to each table above.

One thing to get right: Homebrew derives the class name from the file name, so
`Formula/crt-query.rb` must declare `class CrtQuery < Formula`.
